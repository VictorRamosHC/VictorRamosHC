## Sobre mim

Sou desenvolvedor brasileiro em evolução contínua, com projetos em desenvolvimento web e Android. Uso inteligência artificial para explorar soluções, revisar código, acelerar protótipos e apoiar testes. O escopo, as decisões de arquitetura, a integração e a validação continuam sob minha responsabilidade.

**ProjetoViagem → GlassTask → Prisma House Painter → Aether Vault**
