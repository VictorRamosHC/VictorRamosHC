## ◼ [ 01 // PERFIL DE ENGENHARIA ]

Não me defino por uma única camada do stack. Gosto de entender o sistema inteiro — produto, interface, APIs, dados, automação, observabilidade e segurança — e transformar cada parte em uma solução coerente. Front-end, back-end, banco e infraestrutura são etapas do mesmo processo: quero ser o engenheiro que entende a receita completa e entrega o produto de ponta a ponta.

Tenho interesse contínuo em **cibersegurança** e já tive contato prático com rotinas da área, sem expor detalhes operacionais. O imaginário **cyberpunk** e a cultura hacker me atraem como linguagem visual e crítica aos sistemas de poder; estudo **hacking ético e segurança ofensiva** com responsabilidade.

Uso **IA como ferramenta de engenharia**: prototipo, reviso código e desenho testes com agentes, mantendo arquitetura, integração e validação sob supervisão humana. Minha evolução atravessa ProjetoViagem → GlassTask → Prisma House Painter → Aether Vault.

```text
[ CORP.NET ] [ SURFACE: FULL-STACK ] [ SECURITY: THREAT-AWARE ] [ MODE: BUILD / REFACTOR / HARDEN ]
```
